# Динозаврик — офлайн-игра

Локальная версия игры T-Rex Runner из Google Chrome. Игровой движок, спрайты и звуковые эффекты находятся в проекте; интернет и сервер для запуска не нужны.

## Запуск

Откройте `index.html` в современном браузере (Chrome, Edge, Firefox или Safari).

## Управление

| Действие | Управление |
| --- | --- |
| Начать игру / прыгнуть | Пробел, ↑, клик или касание |
| Присесть | ↓ |
| Быстро опуститься во время прыжка | ↓ |
| Перезапустить после столкновения | Пробел, ↑, Enter или клик |

## Что исправлено

- Добавлен запуск и прыжок мышью на компьютере.
- Исправлена совместимость анимации вступления с браузерами без WebKit-префиксов.
- Добавлена безопасная обработка отсутствующего Web Audio API и поддержка `webkitAudioContext`.
- Устранено повторное создание AudioContext.
- Обновлена обработка изменения системной тёмной темы.
- Подправлена адаптивная вёрстка и подсказки управления.

Игра сохраняет оригинальную механику Chromium: препятствия, ускорение, очки, рекорд, ночной режим, звуки и столкновения.
